# 抗风扰动降落精度提升方案

## 🌪️ 问题分析

飞机在降落过程中受风扰动影响导致降落精度不准的原因：

1. **风力直接影响**：侧风推动飞机偏离目标位置
2. **控制延迟**：系统响应滞后，无法及时补偿风力
3. **高频振荡**：风的突变导致控制输出震荡
4. **积分饱和**：持续风扰动导致PID积分项饱和

### 方案3：自适应PID增强

#### 3.1 基于风力的PID调整
```cpp
// 在calculateAdaptivePID中添加风力因子
if (wind_magnitude > high_wind_threshold) {
    // 大风：增加微分增益，减少积分增益
    kd_factor *= 1.3;
    ki_factor *= 0.7;
} else if (wind_magnitude > medium_wind_threshold) {
    // 中风：适中调整
    kd_factor *= 1.1;
    ki_factor *= 0.9;
}
```

#### 3.2 积分项抗饱和
- 限制积分项范围防止饱和
- 大风时自动重置积分项
- 使用条件积分避免累积误差

## 🔧 参数调优指南

### 滤波器调优
| 参数 | 增加效果 | 减少效果 | 建议范围 |
|------|----------|----------|----------|
| `position_filter_tc` | 更平滑，响应慢 | 响应快，可能震荡 | 0.1-0.5 |
| `velocity_filter_tc` | 更稳定，延迟大 | 响应快，噪声多 | 0.05-0.2 |
| `wind_estimation_filter_tc` | 风估计平滑 | 风估计敏感 | 0.5-2.0 |

### 补偿参数调优
| 参数 | 增加效果 | 减少效果 | 建议范围 |
|------|----------|----------|----------|
| `compensation_gain` | 抗风能力强 | 可能过补偿 | 0.1-0.5 |
| `max_compensation` | 允许大补偿 | 限制补偿幅度 | 0.1-0.3 |

### 自适应增益调优
- **大风环境**：增加 `adaptive_gain_large` 到 1.3
- **小风环境**：增加 `adaptive_gain_small` 到 0.9
- **复杂环境**：保持中等增益为主

## 🛡️ 安全保护

### 1. 补偿限制
- 最大风补偿限制在0.2 m/s以内
- 防止过补偿导致系统不稳定

### 2. 异常检测
- 监控风估计的合理性
- 检测异常大的补偿值
- 自动重置补偿系统

### 3. 降级方案
- 风补偿系统故障时自动禁用
- 回退到原始PID控制
- 保持系统基本功能
