# 二维码降落偏航控制完整使用指南

## 📋 概述

本指南详细说明了二维码降落模式中机头朝向正东方向的偏航控制系统的完整实现、配置和使用方法。

## 🔧 系统改进内容

### 1. 核心功能改进

- **当前朝向跟踪**：从 `/uav2/mavros/local_position/pose` 获取飞机当前偏航角
- **PID偏航控制**：基于朝向误差的精确PID控制
- **统一控制策略**：所有降落模式统一使用东向目标朝向
- **安全保护机制**：异常检测、速率限制、平滑处理

### 2. 技术实现特点

- **精确角度计算**：使用四元数转欧拉角获得准确朝向
- **角度环绕处理**：正确处理-π到π的角度跳跃问题
- **自适应控制**：根据飞行状态动态调整控制参数
- **故障备用**：当朝向数据不可用时自动切换到简化控制

## 📁 修改文件清单

## ⚙️ 配置参数详解

### 基础PID参数
```yaml
yaw_control:
  max_yaw_rate: 0.5     # 最大偏航角速率 (rad/s)
  yaw_p_gain: 1.0       # 比例增益
  yaw_i_gain: 0.1       # 积分增益  
  yaw_d_gain: 0.2       # 微分增益
  target_east_yaw: 0.0  # 目标东向角度 (弧度)
  enable_yaw_control: true  # 启用偏航控制
```

### 安全参数
```yaml
  # 安全参数
  max_rate_change: 0.2      # 最大角速率变化率 (rad/s^2)
  abnormal_rate_threshold: 2.0  # 异常检测阈值倍数
  yaw_tolerance: 0.087      # 偏航角容差 (5度)
  
  # 调试参数
  enable_yaw_debug: true    # 启用调试输出
  debug_print_interval: 3.0 # 调试信息间隔 (秒)
```

### 参数调优建议

| 参数 | 建议范围 | 调优方法 |
|------|----------|----------|
| `yaw_p_gain` | 0.8-1.5 | 增加提高响应速度，减小降低超调 |
| `yaw_i_gain` | 0.05-0.2 | 消除稳态误差，过大会振荡 |
| `yaw_d_gain` | 0.1-0.3 | 减少超调，改善稳定性 |
| `max_yaw_rate` | 0.3-0.8 | 根据飞机特性调整最大转向速度 |

## 📊 调试信息解读

### 标准调试输出
```
Yaw control: current=45.0°, target=0.0°, error=-45.0°, rate=-0.25 rad/s
```

**字段说明：**
- `current`: 当前飞机朝向（度）
- `target`: 目标朝向（度，0°=正东）
- `error`: 朝向误差（度）
- `rate`: 计算的偏航角速率（rad/s）

### 异常情况处理
```
WARN: Abnormal yaw rate detected: 2.50 rad/s, resetting PID
WARN: Current yaw not available, using simplified yaw control
```

## 🔍 故障排除

### 问题1：朝向不更新
**症状：** 调试输出显示朝向始终为0或不变化
**解决：**
1. 检查 `/uav2/mavros/local_position/pose` 话题
2. 确认MAVROS连接正常
3. 验证飞控姿态估计功能

### 问题2：控制不稳定
**症状：** 飞机偏航振荡或超调严重
**解决：**
1. 减小PID积分增益 (`yaw_i_gain`)
2. 增加微分增益 (`yaw_d_gain`)
3. 降低最大偏航角速率 (`max_yaw_rate`)

### 问题3：响应过慢
**症状：** 飞机朝向调整速度太慢
**解决：**
1. 增加比例增益 (`yaw_p_gain`)
2. 提高最大偏航角速率
3. 检查是否有外部干扰

### 问题4：角度跳跃
**症状：** 偏航角出现180°突变
**解决：**
1. 确认使用了 `normalize_angle()` 函数
2. 检查角度环绕处理逻辑
3. 验证四元数到欧拉角转换
