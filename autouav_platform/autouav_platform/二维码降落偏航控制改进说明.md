# 二维码降落偏航控制改进说明

## 问题分析

原系统在二维码降落模式中的偏航角控制存在以下问题：

1. **缺少当前飞机朝向信息**：只使用目标朝向计算角速率，未考虑飞机当前实际朝向
2. **角速率限制过小**：配置中 `max_yaw_rate` 设置为 0.0，完全禁用了偏航控制
3. **缺少PID控制**：偏航控制没有使用PID算法，仅基于简单的差值计算
4. **角度环绕处理不完善**：可能导致角度跳跃和控制不稳定

## 改进方案

### 1. 添加当前飞机朝向跟踪

- 在 `pose_cb()` 回调函数中获取当前飞机朝向
- 使用四元数转欧拉角的方式获取当前偏航角
- 添加朝向数据有效性检查

```cpp
// 获取当前飞机朝向（偏航角）
Eigen::Quaterniond current_quat(msg->pose.orientation.w, 
                                msg->pose.orientation.x,
                                msg->pose.orientation.y, 
                                msg->pose.orientation.z);
current_yaw_ = geometry_utils::get_yaw_from_quaternion(current_quat);
current_yaw_available_ = true;
```

### 2. 实现偏航角PID控制器

- 添加专用的偏航角PID控制器
- 基于朝向误差（目标朝向 - 当前朝向）进行控制
- 使用 `geometry_utils::normalize_angle()` 处理角度环绕

```cpp
// 计算朝向误差（目标朝向 - 当前朝向）
double yaw_error = target_yaw - current_yaw_;
// 处理角度环绕问题（-π到π）
yaw_error = geometry_utils::normalize_angle(yaw_error);
// 使用PID控制器计算偏航角速率
double yaw_rate = yaw_pid_.compute(yaw_error, dt);
```

### 3. 更新配置参数

在 `aruco_land_params.yaml` 中添加偏航控制参数：

```yaml
# Yaw control parameters
yaw_control:
  max_yaw_rate: 0.5         # rad/s - 最大偏航角速率
  yaw_p_gain: 1.0           # 偏航PID比例增益
  yaw_i_gain: 0.1           # 偏航PID积分增益  
  yaw_d_gain: 0.2           # 偏航PID微分增益
  target_east_yaw: 0.0      # 目标东向偏航角（弧度，0=正东）
  enable_yaw_control: true  # 启用偏航控制系统
```

### 4. 改进的控制逻辑

- 添加偏航控制开关，可通过参数启用/禁用
- 提供备用的简化偏航控制方法
- 增加调试信息输出，方便调试和监控

## 主要修改文件

   - 添加PID控制器和相关参数

2. **aruco_land_params.yaml**：
   - 更新偏航控制参数配置
   - 启用偏航控制功能

## 使用说明

### 1. 参数调整

根据实际飞行测试效果，可调整以下参数：

- `max_yaw_rate`：最大偏航角速率，建议0.3-0.8 rad/s
- `yaw_p_gain`：比例增益，影响响应速度，建议0.8-1.5
- `yaw_i_gain`：积分增益，消除稳态误差，建议0.05-0.2
- `yaw_d_gain`：微分增益，减少超调，建议0.1-0.3

### 2. 测试步骤

1. **地面测试**：
   - 启动系统，检查当前朝向是否正确获取
   - 观察调试信息中的朝向数据

2. **悬停测试**：
   - 在安全高度悬停
   - 触发二维码降落模式
   - 观察飞机是否能正确调整朝向至东方

3. **降落测试**：
   - 在二维码平台上方进行完整降落测试
   - 监控整个过程中的朝向控制效果

### 3. 调试信息

系统会输出以下调试信息（每3秒一次）：

```
Yaw control: current=45.0°, target=0.0°, error=-45.0°, rate=-0.25 rad/s
```

- `current`：当前飞机朝向（度）
- `target`：目标朝向（度）
- `error`：朝向误差（度）
- `rate`：计算出的偏航角速率（rad/s）

## 预期效果

实施改进后，二维码降落模式中：

1. **精确朝向控制**：飞机能够准确调整朝向至正东方向（0°）
2. **平稳控制过程**：使用PID控制器实现平稳的朝向调整
3. **安全可靠**：有角速率限制和故障备用机制
4. **可调试监控**：提供详细的调试信息便于优化

## 注意事项

1. **坐标系对应**：确保理解NED坐标系中的偏航角定义（0°=正东，90°=正北）
2. **参数调优**：根据具体飞机特性和飞行环境调整PID参数
3. **安全测试**：建议先在模拟器或安全环境中测试
4. **备用方案**：如果当前朝向数据不可用，系统会自动使用简化控制方法

## 故障排除

1. **朝向不更新**：检查 `/uav2/mavros/local_position/pose` 话题是否正常
2. **控制不稳定**：调整PID参数，特别是减小积分增益
3. **角度跳跃**：确保使用了 `normalize_angle()` 函数处理角度环绕
4. **控制无效**：检查 `enable_yaw_control` 参数是否设置为true
