# 二维码降落高度阈值调整总结

## 🎯 问题解决

根据您的反馈"飞控在5m高度时非常接近地面，二维码检测占图像画面接近全部"，我已经对所有高度阈值进行了大幅调整。

## 📊 高度阈值调整对比

### 主要阈值调整

| 参数 | 原值 | 新值 | 说明 |
|------|------|------|------|
| `HEIGHT_ROUGH_LAND` | 7.0m | **15.0m** | 粗降落切换高度 |
| `HEIGHT_FINE_LAND` | 0.5m | **3.0m** | 精降落/AUTO.LAND切换高度 |

### 粗降落模式高度分层

| 高度范围 | 下降速度 | 水平速度限制 | 说明 |
|----------|----------|--------------|------|

| 10.0-20.0m | -0.6 m/s | 0.4 m/s | 高空适中下降 |
| 5.0-10.0m | -0.4 m/s | 0.3 m/s | 中等高度缓慢下降 |
| < 5.0m | -0.2 m/s | 0.3 m/s | 接近精降落阈值 |

## 🎯 AUTO.LAND触发方式

### 方式1：高度触发（传统方式）
- 触发高度：**3.0米**（从0.5米调整）
- 开关：`enable_height_trigger: true`

### 方式2：时间触发（推荐）
- 精降落持续时间：**15秒**
- 开关：`enable_time_trigger: true`

### 方式3：精度触发
- 位置精度阈值：**0.10**（10%画面误差）
- 开关：`enable_accuracy_trigger: true`

### 方式4：手动触发（最灵活）
```bash
rostopic pub /manual_autoland_trigger std_msgs/Bool "data: true"
```

## 🔧 自适应PID高度因子调整

| 高度范围 | 因子值 | 控制特性 |
|----------|--------|----------|
| > 10.0m | 1.3 (very_high) | 更激进响应 |
| 5.0-10.0m | 1.1 (high) | 稍激进响应 |
| 3.0-5.0m | 0.9 (medium) | 保守响应 |
| < 3.0m | 0.7 (low) | 非常保守 |

## 📋 关键改进点

1. **扩大高度范围**：
   - 粗降落：7m → 15m
   - 精降落：0.5m → 3m

2. **优化速度控制**：
   - 高空下降速度增加（-0.8 m/s）
   - 低空下降速度保持保守

3. **增强安全性**：
   - 多种AUTO.LAND触发方式
   - 改进的模式切换机制
   - 失败重试和状态监控

## 🚀 预期效果

1. **更合理的高度分层**：
   - 15米以上：粗降落（二维码较小，快速接近）
   - 3-15米：精降落（二维码清晰，精确控制）
   - 3米以下：考虑AUTO.LAND（二维码占满画面）

2. **更灵活的切换**：
   - 不完全依赖高度判断
   - 可以手动控制切换时机
   - 多重保护机制

3. **更稳定的控制**：
   - 各高度段都有合适的控制参数
   - 避免在低高度时控制过于激进

## 🛠️ 使用建议

### 立即可用配置
```yaml
# 推荐配置：禁用高度触发，使用手动触发
autoland_trigger:
  enable_height_trigger: false    # 禁用高度触发
  enable_time_trigger: true       # 启用时间触发（备用）
  enable_accuracy_trigger: true   # 启用精度触发（备用）
```

### 测试步骤
1. **高空测试**（15米以上）：验证粗降落模式
2. **中空测试**（3-15米）：验证精降落模式  
3. **低空测试**（3米以下）：验证AUTO.LAND切换
4. **手动触发测试**：在任意高度手动触发AUTO.LAND

### 紧急处理
```bash
# 如果需要立即切换到AUTO.LAND
rostopic pub /manual_autoland_trigger std_msgs/Bool "data: true"

# 如果需要遥控器接管
rosservice call /uav2/mavros/set_mode "custom_mode: 'POSITION'"
```

现在的高度阈值设置更符合实际飞行情况，避免了在5米高度时二维码占满画面但仍在精降落模式的问题。
