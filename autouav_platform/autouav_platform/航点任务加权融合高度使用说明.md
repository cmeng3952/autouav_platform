# 航点任务加权融合高度使用说明

## 🎯 功能概述

在 `mission_waypoint.h` 中实现了激光雷达和ArUco视觉深度的加权融合高度算法，提供更准确和可靠的高度估计用于返航判断。

## 🧮 加权融合算法

### 融合公式
```
融合高度 = (ArUco深度 × ArUco权重 + 激光雷达 × 激光权重 + GPS高度 × GPS权重) / 总权重
```

### 默认权重配置
```yaml
height_fusion:
  aruco_weight: 0.7      # ArUco深度权重（最高）
  lidar_weight: 0.5      # 激光雷达权重（中等）
  gps_weight: 0.3        # GPS权重（最低）
```

### 数据有效性检查
| 数据源 | 有效性条件 | 超时时间 |
|--------|------------|----------|
| ArUco深度 | 0.1m < depth < 50.0m | 1秒 |
| 激光雷达 | min_range < range < max_range | 2秒 |
| GPS高度 | 0.0m < height < 100.0m | 无超时 |

## 🔍 实际融合示例

### 示例1：所有数据源可用
```
输入数据：
- ArUco深度：8.2m（权重0.7）
- 激光雷达：8.0m（权重0.5）
- GPS高度：7.8m（权重0.3）

计算过程：
融合高度 = (8.2×0.7 + 8.0×0.5 + 7.8×0.3) / (0.7+0.5+0.3)
         = (5.74 + 4.0 + 2.34) / 1.5
         = 12.08 / 1.5 = 8.05m
```

### 示例2：部分数据源可用
```
输入数据：
- ArUco深度：不可用
- 激光雷达：8.1m（权重0.5）
- GPS高度：7.9m（权重0.3）

计算过程：
融合高度 = (8.1×0.5 + 7.9×0.3) / (0.5+0.3)
         = (4.05 + 2.37) / 0.8
         = 6.42 / 0.8 = 8.02m
```

### 推荐配置3：平衡配置（默认）

height_fusion:

## 🔧 参数调优指南

### 权重调整原则

1. **ArUco权重调整**
   - **增加**：视觉检测稳定，二维码清晰
   - **减少**：光照条件差，检测不稳定

2. **激光雷达权重调整**
   - **增加**：地面平整，测距准确
   - **减少**：地面不平，或有遮挡物

3. **GPS权重调整**
   - **增加**：GPS信号强，定位准确
   - **减少**：GPS漂移严重，或室内环境

### 调优步骤

1. **观察数据质量**
   ```bash
   rostopic echo /rosout | grep "Height fusion"
   ```

2. **比较各数据源**
   - 查看各高度源的数值差异
   - 识别哪个数据源更准确

3. **调整权重配置**
   - 增加准确数据源的权重
   - 减少不准确数据源的权重

4. **验证融合效果**
   - 观察融合高度的稳定性
   - 确认返航判断的准确性

## 🔍 故障诊断

### 问题1：融合高度跳跃
**症状：** 融合高度值不稳定
**解决：**
1. 检查各数据源稳定性
2. 调整权重比例
3. 增加数据过滤

### 问题2：某个数据源异常
**症状：** 调试输出显示某数据源异常
**解决：**
1. 检查对应传感器状态
2. 临时降低该数据源权重
3. 增加其他数据源权重

### 问题3：融合结果不准确
**症状：** 融合高度与实际高度差异大
**解决：**
1. 校准各传感器
2. 重新评估权重分配
3. 检查环境因素影响

## 💡 优化建议

### 1. 动态权重调整
可以根据数据质量动态调整权重：
```cpp
// 示例：根据数据方差调整权重
if (aruco_data_variance < threshold) {
    aruco_weight *= 1.2;  // 数据稳定时增加权重
}
```

### 2. 异常检测
添加异常数据检测和过滤：
```cpp
// 检查数据源之间的一致性
double max_diff = max(abs(aruco-lidar), abs(aruco-gps), abs(lidar-gps));
if (max_diff > threshold) {
    // 数据不一致，降低权重或排除异常数据
}
```

### 3. 自适应融合
根据飞行阶段调整权重：
- **高空**：GPS权重较高
- **中空**：激光雷达权重较高  
- **低空**：ArUco权重较高

## 🎯 预期效果

1. **更平滑的高度估计**：加权融合减少单一数据源的噪声影响
2. **更准确的返航判断**：多源验证提高判断可靠性
3. **更好的故障容错**：单一数据源失效时自动降权
4. **更详细的监控**：实时了解各数据源状态和融合效果

这个加权融合实现让您能够充分利用激光雷达和ArUco视觉深度的优势，获得比单一数据源更准确和稳定的高度估计。
