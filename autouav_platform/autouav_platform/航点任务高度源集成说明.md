# 航点任务高度源集成说明

## 🎯 功能概述

成功在 `mission_waypoint.h` 中集成了与二维码降落系统相同的高度数据源（激光雷达 + ArUco深度），使航点任务中的高度判断更加准确和一致。

## 🔧 技术实现

### 1. 新增数据源订阅
```cpp
// 激光雷达数据
lidar_sub_ = nh_.subscribe<sensor_msgs::Range>("/mavros/distance_sensor/hrlv_ez4_pub", 
                                              &MissionController::lidarCallback, this);

// ArUco检测数据（提取深度信息）
aruco_detection_sub_ = nh_.subscribe<vision_msgs::TargetsInFrame>("/vision/aruco_detection",
                                                                 &MissionController::arucoDetectionCallback, this);
```

### 2. 融合高度计算

### 3. 改进的高度判断

## 📊 数据源优先级

| 优先级 | 数据源 | 条件 | 说明 |
|--------|--------|------|------|
| 1 | **ArUco深度** | 数据新鲜(<1秒) + 合理范围 | 与视觉检测同步，最准确 |
| 2 | **激光雷达** | 数据新鲜(<2秒) + 有效范围 | 可靠的地面距离测量 |
| 3 | **GPS高度差** | GPS可用 | 备用方案 |

## 🔍 主要改进

### 改进前
- 仅使用GPS高度差：`current_alt_ - takeoff_alt_`
- 高度范围：5-12米
- 可能存在GPS高度不准确问题

### 改进后
- 融合多种高度源：ArUco深度 + 激光雷达 + GPS
- 高度范围：5-15米（更宽松合理）
- 详细的调试信息输出

## 📋 调试信息输出

### 距离检查信息
```
Distance check: horiz=1.2m (OK<1.5m), fused_height=8.5m, gps_height=8.3m, range=OK(5-15m)
```

### 高度源状态
```
Height sources: Lidar=OK(8.4m), ArUco=OK(8.6m), GPS=8.3m
```

**字段说明：**
- `horiz`: 水平距离（米）
- `fused_height`: 融合高度（米）
- `gps_height`: GPS高度差（米）
- `Lidar`: 激光雷达状态和数值
- `ArUco`: ArUco深度状态和数值
- `GPS`: GPS高度差数值

## ⚙️ 配置建议

### 数据源超时设置
- **ArUco数据超时**：1秒（视觉检测更新频率较高）
- **激光雷达超时**：2秒（传感器数据相对稳定）

### 高度范围调整
- **最低高度**：5米（确保安全降落高度）
- **最高高度**：15米（避免过高触发降落）

## 🔍 故障排除

### 问题1：ArUco深度数据无效
**症状：** 调试输出显示 `ArUco=FAIL`
**解决：**
1. 检查二维码检测是否正常
2. 确认ID19或43标记可见
3. 验证深度数据范围（0.1-50m）

### 问题2：激光雷达数据异常
**症状：** 调试输出显示 `Lidar=FAIL`
**解决：**
1. 检查激光雷达话题数据
2. 验证传感器连接
3. 确认数据范围有效

### 问题3：高度判断不一致
**症状：** 不同高度源差异较大
**解决：**
1. 比较各高度源数值
2. 检查传感器安装位置
3. 考虑环境因素影响

## 🔧 技术细节

### 数据新鲜度检查
```cpp
// ArUco数据：1秒超时（视觉检测频率高）
bool aruco_fresh = (ros::Time::now() - last_aruco_time_).toSec() < 1.0;

// 激光雷达数据：2秒超时（传感器稳定）
bool lidar_fresh = (ros::Time::now() - last_lidar_time_).toSec() < 2.0;
```

### 优先级选择逻辑
1. **ArUco深度优先**：与视觉检测同步，精度高
2. **激光雷达备用**：可靠的地面距离测量
3. **GPS高度保底**：确保系统不会失去高度信息

这个实现确保了航点任务中的高度判断与二维码降落系统完全一致，使用相同的传感器数据源，提供更准确和可靠的高度估计。
